# scoop-bucket

[Scoop](https://scoop.sh) manifests for [meow](https://github.com/ericliswan/termeownal), Instagram DMs in your terminal.

```powershell
scoop bucket add ericliswan https://github.com/ericliswan/scoop-bucket
scoop install meow
```

Update with `scoop update meow`. The manifests are written by the release workflow in termeownal; don't edit them by hand.
